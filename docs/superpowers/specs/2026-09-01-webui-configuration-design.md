# WebUI 配置中心设计

## 目标

为插件新增 AstrBot Plugin Page，让管理员在同一页面管理全部现有配置，并提供运行状态、配置导入导出和图源 API 检测。保存结果写回 AstrBot 注入的配置对象并持久化，插件后续处理立即读取新值。

## 范围

- 覆盖 `_conf_schema.json` 中的全部字段。
- 为 `sources` 提供卡片式专用编辑器，支持增删、排序和列表字段编辑。
- 为普通配置提供分组表单：发送设置、图片处理和文本设置。
- 提供配置读取、保存、导入、导出、运行状态和单地址 API 检测接口。
- 保持现有消息指令与图片获取行为不变。

## 页面结构

页面使用 `pages/settings/index.html` 作为入口，并通过外部 JavaScript 和 CSS 提供交互与样式。页面使用 `window.AstrBotPluginPage` bridge，不直接访问 Dashboard 的 Cookie、存储或父页面 DOM。

### 图源管理

每个图源以可折叠卡片展示以下字段：

- 名称
- 触发词列表
- API 地址列表
- 合并转发开关
- 名单模式
- 群号列表
- 自动撤回时间

每条 API 地址由输入框、检测按钮和删除按钮组成。检测读取当前输入值，因此未保存的新地址也可测试。结果在地址下方显示可用状态、响应耗时、HTTP 状态、内容类型或错误原因。检测期间只锁定对应按钮。

图源折叠状态使用页面内稳定身份维护，与提交给后端的配置数据分离。增删触发词、API 地址或群号，以及图源排序后，所有已展开图源保持展开；新增图源自动展开并聚焦名称。未保存的新图源直接删除，已保存图源通过页面内可访问确认对话框删除，删除后自动展开相邻图源。

### 其他配置

- 发送设置：批量强制转发、转发阈值、单次最大张数、失败重试和全局冷却。
- 图片处理：自动压缩、压缩阈值、压缩质量和 SSL 证书验证。
- 文本设置：猫娘模式与后缀。
- 运行状态：插件版本、图源数量、HTTP 会话状态、冷却记录数量和最近保存时间。

## 数据流与接口

插件初始化时注册以插件名为前缀的 Web API。Page 使用相对 endpoint 调用：

1. `GET config`：返回当前配置和页面需要的 schema 元数据。
2. `POST config/save`：校验完整配置，更新现有配置对象并调用 `save_config()`。
3. `POST api/test`：检测一个当前输入的图源地址并返回状态与耗时。
4. `GET status`：返回只读运行状态。
5. `GET config/export`：下载当前配置 JSON。
6. `POST config/import`：校验上传或读取后的 JSON，返回变更摘要并在确认后保存。

保存时保持 `self.cfg` 的对象身份，使用清空并更新的方式同步内容。若 `verify_ssl` 发生变化，关闭当前 HTTP 会话，使下一次请求以新 SSL 配置重建连接。

## 校验与错误处理

- 后端是最终校验边界。为了兼容 AstrBot 配置升级，未知字段会被清理，缺失字段按 schema 默认值补齐；明确提供的已知字段仍严格检查类型、数值上下限、枚举和 URL，图源子项遵循相同规则。
- 至少保留一个有效图源；图源名称、触发词和 API 地址去除首尾空白。
- API 检测仅接受 HTTP/HTTPS 地址，并复用插件已有的私网地址拦截和受限跳转逻辑。
- 导入先解析、校验并展示变更摘要，用户确认后才覆盖当前配置。
- 页面统一显示加载、保存、检测和导入错误，保留用户尚未保存的输入。
- 校验失败时显示错误总数，自动展开包含首个错误的图源，并聚焦、滚动到首个可修正字段。

## 视觉与可访问性

- 使用 AstrBot bridge 上下文响应亮暗主题变化。
- 主题采用中等饱和度蓝粉渐变作为标题、主要操作和背景光晕，亮暗模式分别提供足够的文字与焦点对比度。
- 响应式布局适配桌面与窄屏。
- 所有表单控件具有可见标签、键盘焦点和明确的错误文本。
- 页面跟踪脏状态，在刷新或离开前提示未保存修改。

## 验证标准

- Page 能在 AstrBot 插件详情中被发现并打开。
- 当前全部配置可正确加载、编辑、保存并持久化。
- 保存后的运行时逻辑立即读取新配置；SSL 变化会重建会话。
- 每条 API 地址后的检测按钮能独立工作并原位显示结果。
- 导出文件可再次导入；非法配置会得到字段级错误且不会覆盖现有配置。
- 页面在亮暗主题、桌面和窄屏下可用。
- Python 语法检查、JSON 校验和页面脚本静态检查通过。
